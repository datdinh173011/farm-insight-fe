# Web Form câu hỏi (React + antd)

Dự án nhỏ chứa một form đầu tiên để thu thập thông tin cơ bản của người được phỏng vấn và lựa chọn 1 trong 6 kỹ thuật.

## Yêu cầu
- Node.js (v16+) và npm

## Cài đặt & chạy (Windows PowerShell)

```powershell
cd D:\Form\Web_Form
npm install
npm run dev
```

Sau khi chạy `npm run dev`, mở trình duyệt tới địa chỉ hiển thị trong terminal (mặc định là http://localhost:5173).

## Ghi chú
- Form sử dụng `antd` (Ant Design). Khi ấn Gửi, dữ liệu sẽ được in ra console và có thông báo thành công.
- Bạn có thể mở DevTools -> Console để xem object dữ liệu gửi lên.
